Importer un référentiel

Remplacez l'édition du code par un import structuré. Le fichier doit décrire la hiérarchie référentiel → dimensions → capacités → niveaux/critères.

Un référentiel déjà utilisé par des évaluations validées ne peut pas être modifié en place : l'import crée une nouvelle version.

{
  "label": "Design-org v2",
  "description": "Référentiel Design pour les organisations",
  "cible": "organisation",
  "dimensions": [
    {
      "numero": 1,
      "nom": "Vision & positionnement",
      "capacites": [
        {
          "numero": "1.1",
          "nom": "Vision stratégique",
          "portee": "P",
          "niveaux": [
            { "niveau": 1, "nom": "Absent", "description": "Aucune vision formalisée." },
            { "niveau": 2, "nom": "Engagé", "description": "Une vision existe, portée par quelques personnes." },
            { "niveau": 3, "nom": "Systématisé", "description": "Vision partagée, revue et pilotée." }
          ]
        }
      ]
    }
  ]
}
